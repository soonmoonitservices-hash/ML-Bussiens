# Features

Die verbindliche, ausführliche Feature-Beschreibung steht in
[`../SPEC.md`](../SPEC.md), Abschnitte 10 und 11. Neuere technische
Konkretisierungen in [`technical.md`](technical.md) gehen vor.

Die App umfasst Authentifizierung, Benutzer und Fahrer, Produkte und Lager,
Touren, Ausgaben, Lieferscheine, Rechnungen sowie Auswertungen. Fahrer erhalten
keinen eigenen Zugang; Empfänger werden frei eingegeben, es gibt keine
Kundenverwaltung.

Der tatsächliche Implementierungsstand steht in
[`../implementation_status.md`](../implementation_status.md).
